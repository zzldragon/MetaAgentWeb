# abc

Multi-agent app generated by MetaAgent.

Pattern mode: chain

Agents: agent

LLMs per agent:
- agent: deepseek-ai/DeepSeek-V4-Flash

## Run

    pip install -r requirements.txt
    python agent.py "your task"

API keys live in config.json under each agent's entry.

## Debug

system_prompts.json lists each agent's resolved system prompt (base persona + route tail + skills + tool guidance), matching what build_system() sends at startup.

## Health of the runs

Every run appends a JSONL trace to traces/. trace_stats.py ships with this project, so it works on the deployed machine with nothing extra installed:

    python trace_stats.py traces             # rates + latency
    python trace_stats.py traces --since 24  # last 24h only
    python trace_stats.py traces --json      # machine-readable

It reports finished / errored / incomplete run rates, tool-error, retry and cache rates, p50-p95 latency and token totals. Pass several traces/ folders to aggregate a whole fleet.
